Defaults are Genetec's documented Security Desk shortcuts. If you customised them (Options → Keyboard shortcuts), type yours here. Format: Ctrl+Shift+F5; sequences with spaces, e.g. 3 Shift+Insert. Keys: Ctrl / Alt / Shift, A–Z, 0–9, F1–F12, Space, Tab, Esc, Enter, Backspace, Insert, Home, arrows, Plus, Minus, Comma, Period, Grave. Shortcuts go to the front window — use the Activate key first.
